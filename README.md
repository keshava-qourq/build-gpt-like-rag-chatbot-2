# Build a GPT-Like RAG Chatbot

Build a modern, production-ready RAG chatbot similar to GPT.

### Requirements
- Modern ChatGPT-style UI with sidebar, chat history, new chat, and responsive design.
- Upload PDF, DOCX, TXT, CSV and Markdown documents.
- Extract → chunk → embed → store documents in a vector database.
- Use semantic search to retrieve relevant document chunks.
- Use conversation history for contextual follow-up questions.
- Stream LLM responses in real time.
- Show clickable citations/sources for retrieved content.
- Never hallucinate; if information is unavailable, clearly say so.
- Support Markdown, code blocks, tables, copy and regenerate.
- Use clean modular architecture.

### Stack
- Frontend: React + TypeScript
- Backend: Python + FastAPI
- Database: PostgreSQL + pgvector
- LLM: configurable provider
- Embeddings: configurable provider
- Deployment: Docker + AWS

### Core Flow

```text
Upload → Extract → Chunk → Embed → pgvector
                                      ↓
Question → Retrieve → Context → LLM → Streaming Answer + Citations
```

Build the complete working flow, not a mock UI.

Generated by the Quorq AI SDLC platform. Two applications, one repository:

- **`frontend/`** -- the approved app design as a Vite + React SPA. Every screen
  was reviewed and approved, and runs on seeded sample data.
- **`backend/`** -- a FastAPI service. No architecture had been approved
  when this repository was created, so it starts with its health check and
  nothing else.

## Running it

```bash
cd frontend
npm install
npm run dev
npm test          # unit tests (Vitest)
npm run lint       # ESLint
npm run format     # Prettier
```

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload
pytest
ruff check .
ruff format .
```
